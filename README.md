# Auto Typer

Auto Typer is a simple Discord auto typer/selfbot project that sends messages to a selected channel at a configurable interval. It can send one fixed message or generate short random messages through `generator.js`.

> **Warning:** User-account automation may violate Discord's Terms of Service. Use this project responsibly, only in places where you have permission, and never use it for spam or abuse.

## Features

- Sends automatic messages to a selected Discord channel
- Supports fixed-message mode and random-message generator mode
- Supports multiple tokens
- Includes a live terminal dashboard
- Provides admin-only start/stop commands
- Keeps private config values out of Git

## Requirements

- Node.js 16.11 or newer
- npm

## Installation

Install dependencies:

```bash
npm install
```

Copy the example config file:

```bash
cp config.example.json config.json
```

Then edit `config.json` with your own values.

## Configuration

```json
{
    "MESAJ_GONDERIM_SURESI": 600000,
    "CHANNEL_ID": "YOUR_CHANNEL_ID",
    "TOKENLER": [
        "YOUR_TOKEN_HERE"
    ],

    "message": "Auto Typer automatic message.",
    "generatorjs": true,
    "onlyonemessage": false,
    "prefix": ".",
    "adminID": "YOUR_ADMIN_ID"
}
```

| Key | Description |
| --- | --- |
| `MESAJ_GONDERIM_SURESI` | Message interval in milliseconds. `600000` equals 10 minutes. |
| `CHANNEL_ID` | The Discord channel ID where messages will be sent. |
| `TOKENLER` | List of account tokens. Keep these private. |
| `message` | The fixed message used when `onlyonemessage` is enabled. |
| `generatorjs` | When `true`, messages are generated by `generator.js`. |
| `onlyonemessage` | When `true`, only the fixed `message` value is sent. |
| `prefix` | Command prefix. The default value is `.`. |
| `adminID` | Discord user ID allowed to use commands. |

If both `generatorjs` and `onlyonemessage` are set to `true`, `generator.js` takes priority.

## Usage

Start the project:

```bash
npm start
```

Run a syntax check:

```bash
npm test
```

On Windows, you can also run:

```bat
başlat.bat
```

## Commands

Only the user configured as `adminID` can use commands.

| Command | Aliases | Description |
| --- | --- | --- |
| `.başlat` | `.baslat`, `.start` | Starts or resumes automatic messages. |
| `.durdur` | `.stop` | Stops automatic messages. |

If you change the `prefix` value in `config.json`, replace `.` with your selected prefix.
